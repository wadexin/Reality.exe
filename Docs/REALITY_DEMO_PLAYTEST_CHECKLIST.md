# Reality.exe Blind Playtest Observation Sheet

Use one copy per blind run. Record what the player actually does. Do not coach unless the run cannot continue.

## Tester instructions

Give the tester only this:

> Play until you believe the Demo is finished. Please think aloud if comfortable. If you become stuck, use anything the game itself provides before asking for help.

If operating controls must be supplied, use only:

> Move: WASD · Look: Mouse · Jump: Space · Interact: E · Reality maintenance: F6 · System menu: Esc

Do not explain puzzle solutions, ability order, SensorFailure, Suspicion math, checkpoints, or intended routes.
